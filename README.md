# Poker Ligi

Haftalık poker oyunlarımızın lig tablosu: https://72-o.github.io

- **Veri:** `data/db.json` dosyasındaki oyuncular ve oyunlar. Her şey bu dosyadan hesaplanır.
- **Giriş:** Sitedeki *Yeni Veri* sekmesinden yapılır, her değişiklik bu repoda bir commit olarak kalır.
- **Yayın:** Her değişiklikte GitHub Actions siteyi ve paylaşım görsellerini yeniden üretir (`scripts/build.mjs`).

Kurallar ve sütunların anlamı sitedeki *Yardım* sekmesinde.
